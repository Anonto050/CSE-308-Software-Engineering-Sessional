# CSE 308 `Software Engineering Sessional`

## How to run on VS Code
- Clone the repository to your local machine.
- Open workspace settings [`.vscode/settings.json`](/.vscode/settings.json) in VS Code.
- Change the `java.project.sourcePaths` in the `settings.json` file of the workspace accordingly. Keep the parent directory of the main class of the desired problem only (e.g., `offline-1/solution-1`).
- Run the main class of the desired problem.
